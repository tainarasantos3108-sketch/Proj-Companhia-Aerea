# ✈️ Sistema de Companhia Aérea

Sistema desktop desenvolvido em **C# com Windows Forms e SQL Server**, voltado ao gerenciamento de operações de uma companhia aérea.

### Funcionalidades principais
- Cadastro e gerenciamento de passageiros.
- Controle e gerenciamento de voos.
- Agendamento de passageiros e emissão de cartões de embarque.
- Registro e gerenciamento de pagamentos.
- Cadastro e gerenciamento de funcionários e setores.
- Consultas e relatórios.

### Tecnologias utilizadas
- C#
- Windows Forms
- .NET Framework 4.7.2
- SQL Server
- ADO.NET
- SQL
- Microsoft ReportViewer

### Conceitos aplicados
- Programação Orientada a Objetos (POO).
- Operações CRUD (Create, Read, Update e Delete).
- Integração entre aplicação desktop e banco de dados.
- Desenvolvimento de interfaces gráficas.
